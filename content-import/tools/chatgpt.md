## Overview

ChatGPT is OpenAI's conversational assistant and, for most people, the on-ramp to using AI day to day. It handles writing, brainstorming, summarising, coding help and general questions in one text box.

## What it's good at

The strength is breadth. You can draft an email, debug a function, outline a blog post and translate a paragraph in the same session without switching tools. The paid tier adds better models, image input, data analysis and web browsing, which closes most of the gaps the free tier has.

## Where it falls short

It still confidently invents facts, so anything factual needs checking. Long, multi-step tasks drift, and it has no persistent memory of your projects unless you spell things out each time. Heavy users will also hit rate limits on the free plan.

## Should you use it?

If you're new to AI tools, start here — it's the safest, most capable generalist. Power users who write or code every day will get their money's worth from Plus.
